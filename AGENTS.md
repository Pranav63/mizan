# Project instructions

- Keep this independent of any employer work. Use original synthetic or permitted public examples.
- Credentials are backend-only. Never print, commit, export or expose key values.
- Demo fixtures must be labelled as illustrative; never attribute their scores to Jev or GPT.
- Do not send ground-truth labels or paired variants to a model being evaluated.
- Preserve model versions, rubric, protocol and dataset/prompt hashes in run exports.
- Failed classifications count as misses. Do not turn errors or missing outputs into matching labels.
- Keep Arabic direction and accessibility intact; glass effects belong on navigation, not result content.
- Run relevant backend tests, frontend build and browser checks after changing those surfaces.
- Live inference consumes credits. Use small runs for integration checks, and do not automatically redispatch interrupted jobs.
